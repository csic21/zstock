# AI 策略实验室

策略实验室采用“AI 提出假设，本地程序验证假设”的边界。AI 输出只能进入版本化、白名单的策略 DSL；数据冻结、信号、成交、费用、指标、证据等级和晋级结论都由本地确定性代码计算。它是研究工具，不构成投资建议，也不连接真实券商。

## 使用流程

1. 在研究页加载一个标的的前复权日 K，进入标题栏「策略实验室」。
2. 在「实验配置」选择 3–5 个策略，并选择模板来源：通用模板，或与「现在找」对齐的扫描规则（强势回踩 / 放量突破 / 超跌反弹 / 寻宝低位）。扫描规则默认使用更短持有和更紧的止盈止损。点击“AI 生成”会使用设置中的 Responses、兼容 Chat API 或只读 CLI；未配置、超时或输出无效时自动使用本地通用模板。
3. 创建实验时，当前 K 线被复制进不可变 SQLite 数据集。正式比较应通过同一数据集接口冻结 50–100 只股票；单股入口会把幸存者偏差写入报告。
4. 「策略草案」展示假设、来源、规范化规则和本地校验。任何未知操作符、未来 lag、超限周期、空退出或过深表达式都会被拒绝。
5. 点击“后台批量运行”。任务可取消；已完成的部分报告会保存，实验与数据库共同进入 `cancelled`，之后可以重新运行。
6. 「排行榜」先应用数据完整性、样本量、样本外超额、回撤、2×成本、集中度和参数稳定性硬门槛，再展示多目标指标。AI 解释缺失不会改变排序。
7. 从排行榜进入「证据报告」，可查看冻结输入版本、基准、成本、训练/验证/walk-forward、权益、风险指标和逐笔交易的信号日与成交日。
8. 只有结论为“模拟盘候选”的策略才能锁定版本并进入每日观察。应用每日首次启动会幂等更新理论信号，也可手动更新。
9. 「策略库」跨实验自动保留未取消的已完成回测。默认按胜率排序，也可按超额、回撤、交易数或入库时间浏览；支持删除单条记录。删除只影响策略库，不删除原始实验。胜率排序用于比较，不能单独作为晋级依据。

## 数据与执行假设

- 日线信号只读取当日及之前数据，按下一有效交易日开盘成交。
- A 股遵守 100 股整数手、现金和最大持仓约束；卖出税、双边佣金、最低佣金、其他费用和双边滑点分开计算。
- 停牌、零成交量、无下一交易日、无效开盘价、现金不足和超期订单都有机器可读拒绝原因。
- 数据集 ID 覆盖标的、行情源、复权、区间和 OHLCV 内容；修改源数据会产生新数据集，不覆盖旧实验。
- 封存测试集只允许显式消费一次。查看后写入 `test_consumed_at`；修改参数必须产生新的策略 ID。

## 模拟观察

模拟观察重新使用锁定的策略版本和冻结/新增日 K，记录理论入场、理论退出、待下一开盘、停牌、无效开盘和错过原因。事件 ID 由候选、标的、日期和信号类型生成；同一天重复运行不会重复创建信号或交易。

页面会比较模拟与回测的信号/交易数、平均持有期、无法成交比例和开盘跳空。最低观察条件是连续 4–8 周或至少 20 个新信号；满足条件只表示“值得继续研究”，不保证未来盈利。

## 本地文件、导出与恢复

- 主数据库：应用数据目录下 `strategy-lab.sqlite3`，使用 bundled SQLite、WAL、外键和事务迁移。
- 导出：证据报告或模拟候选页点击“导出”，生成 `strategy-lab-export-YYYYMMDD-HHMMSS.json`，包含实验、策略、回测与模拟记录，不包含 API Key。
- 数据库适配器支持一致性备份和恢复；恢复后会重新执行迁移并保留不可变数据集、交易和权益序列。
- 设置 `ZSTOCK_DATA_DIR` 可把数据库和导出重定向到隔离目录，便于测试或手工备份。

不要把导出中的历史收益当作未来承诺。免费行情可能存在幸存者偏差、复权修订和缺失历史成分股；这些限制会随冻结数据集写入报告。

## Release 性能基线

2026-08-10 在 macOS arm64、`--release` 下运行固定的 100 只股票 × 5 个策略 × 1000 根日 K fixture：组合回测 659 ms，采样峰值 RSS 112,558,080 bytes，包含冻结 K 线和五份报告的 SQLite 文件 92,852,224 bytes，首次恢复实验 31 ms，内存中切换报告 500 次约 12 µs。基线测试默认 ignored，可用下列命令复测：

```bash
rtk proxy cargo test --release performance_database_open_and_report_switch_baseline -- --ignored --nocapture
```
