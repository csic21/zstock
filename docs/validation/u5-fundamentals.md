# U5 point-in-time 基本面证据

验证日期：2026-08-09（Asia/Shanghai）

## 数据源与字段

| 证据 | 市场 | 可追溯来源 | point-in-time 口径 |
|---|---|---|---|
| ROE/ROIC、现金利润匹配、负债率、营收和利润增长 | A 股 | 东方财富 `RPT_F10_FINANCE_MAINFINADATA` | 使用接口 `NOTICE_DATE`；同报告期与资产负债表取较晚公告日 |
| 商誉/总资产、审计意见 | A 股 | 东方财富 `RPT_F10_FINANCE_GBALANCE` | 值、单位、报告期、公告日和来源逐项保存；缺失保持未知 |
| ROE/ROIC、现金利润匹配、负债率、营收和利润增长 | 港股 | 东方财富 `RPT_HKF10_FN_MAININDICATOR` | 报告期不充当公告日；必须匹配下表的业绩公告分类 |
| 商誉/总资产 | 港股 | 东方财富 `RPT_HKF10_FN_BALANCE_PC` 标准项目 `004001005` / `004009999` | 与同报告期的业绩公告日绑定；没有独立商誉项目时保持未知 |
| 财报公告日 | 港股 | 东方财富港股公告列表 `ann_type=H` | 末期业绩 `011001003005`、中期业绩 `011001003007`、季度业绩 `011001003011`；取报告期后 210 天内首个对应公告，无法匹配则整期不用 |
| 分红连续性 | A 股/港股 | 东方财富 `RPT_SHAREBONUS_DET` / `RPT_HKF10_MAIN_DIVBASIC` | 按财政年度和首次方案/分红公告日生成时间线；公告缺失时记录未知，不把缺失推断为零分红 |
| PE(TTM)、PB 三年历史分位 | A 股/港股 | 百度股市通公开估值历史 | 对覆盖接近三年窗口的末端日期，只使用当日及之前的有限值计算扩展分位；信号日后的点不会进入当时门禁，覆盖不足时保持未知 |

港股免费结构化数据没有可靠的审计意见字段。系统不会从核数师名称、报告日期或公告标题推断审计结论，而是明确显示“审计意见未知”。这符合“缺失不能默认通过”的门禁规则。

## 防泄漏与失败语义

- `quality_gate` 先选择信号日已公开的最新报告期，再判断值是否存在；最新一期缺失不会回退到旧期已知值。
- 港股财务期只有匹配到对应业绩公告分类后才进入快照，不能用 `REPORT_DATE` 伪装公告日。
- 分红连续性按公告时间逐步更新；特别分配不替代年度连续性。
- PE/PB 分位为逐日扩展计算，只发布窗口跨度至少 1,080 天的点；后续估值不会重写较早日期的分位。
- 任一必要来源请求失败时，完整 Provider 返回不可用；UI 不会把部分数据当作质量门槛通过。

## 自动化与真实接口证据

离线 fixture 覆盖：

- 港股末期/季度公告分类匹配和未公告财务期剔除。
- 港股商誉/总资产单位换算与审计意见缺失。
- 分红财政年度断档、特别分配排除和未见分红公告时保持未知。
- 估值逐日扩展分位不读取未来值。
- 最新报告期字段缺失时不回退旧报告。
