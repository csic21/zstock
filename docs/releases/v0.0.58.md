# ZStock 0.0.58

## 修复与改进

- 图表数据按股票、周期和请求身份隔离，切换股票或周期时避免旧请求覆盖当前图表。
- 策略分析、模拟交易和研究操作使用独立的标准日 K 数据，不再误用当前图表周期；日线请求可跨图表周期切换继续完成。
- 新画线绑定精确图表周期和时间布局；旧版缺少周期信息的画线保留存档并隐藏，避免在错误周期显示。
- 行情展示区分数据来源和新鲜度，缺失或过期数据不会被默认为实时行情。
- 持仓估值明确标记缺失行情和不完整估值，避免将部分持仓覆盖误当作完整组合收益。
- 本地成交记录草稿绑定股票和复核状态，提交前可检查明细，并支持撤销最近的本地记录操作。
- 搜索和市场成分股入口先打开研究预览；加入自选为明确操作，自选变更支持撤销。
- 自选和界面设置保存不再依赖系统凭据库；API Key 修改单独处理，普通自动化测试使用隔离的内存凭据库。
- 发布流程等待全部平台构建完成，核对全部安装包后再公开 Release，并使用真实 ZIP 文件的 SHA-256 更新稳定版清单。

## 安装包

- macOS Apple Silicon / Intel：ZIP、DMG、PKG
- Windows x64：ZIP、安装器 EXE
- Linux x64：ZIP

## 验证范围与限制

发布由 Linux、Windows、macOS arm64 和 macOS x64 的质量检查及平台打包任务把关。自动化测试不能替代真实桌面 GUI 验收；本次未声称已完成真实桌面 GUI 验证。

本软件提供研究和本地成交记录功能，不会代替券商执行交易。本次修复改善数据一致性与操作安全性，不构成投资建议，也不代表或保证投资收益。
