# ZStock 0.0.59

## 界面与操作

- 内置并注册组件 SVG 图标，修复工具栏只剩空白按钮的问题；常用入口恢复图标和短文字标签。
- 修复组件库将按钮悬停文字固定为红色的问题，恢复各按钮类型应有的文字颜色。
- 统一工具栏点击区域、间距和选中状态；设置页的返回按钮不再与后台页面同时突出显示。
- 设置页使用更易读的字号、分组和可换行选项，更新搜索、自选移除等快捷键说明。
- 从设置页点击当前栏目也能返回；在今日、研究等页面之间切换时保留分析标签。
- 搜索完整 A 股或港股代码后按 Enter 可立即打开预览，不再等待名称搜索结束；加入自选仍需明确操作。

## 性能

- 策略库更新时准备可执行策略，页面重绘不再重复查询 SQLite 和编译同一策略。
- 单只股票持仓查询只重放相关流水；今日页复用一次持仓结果，减少重复重算。
- 移除自选数量展示中的重复排序，以及日 K 缓存读取中的多余复制。
- 保留原有行情新鲜度、币种分组、策略身份校验及异步请求失效保护。

## 验证

新增真实组件图标读取、生产工具栏布局、页面返回、搜索取消、持仓等价性及策略缓存更新回归测试；增加隔离数据目录下的 Linux 原生界面截图检查。

性能热点的微基准与完整桌面帧率是不同指标，不能将前者视为所有设备上的流畅度保证。Linux 截图不替代 macOS 或 Windows 真机验收。

macOS 安装包沿用 ad-hoc 签名，未公证。本软件用于研究与本地记录，不执行券商交易。
