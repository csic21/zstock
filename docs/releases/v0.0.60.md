# ZStock 0.0.60

## 数据保护

- 持仓或决策日记读取、校验、迁移失败时进入明确的只读恢复模式，阻止继续写入覆盖原文件。
- 设置页提供需要再次确认的备份恢复和重置；操作前保留原始字节，备份进行同步落盘。
- 配置、系统凭据、持仓、日记等写入交给有序后台队列，合并等待中的重复快照，显示待保存、完成和失败状态。

## 更新安全

- 自动更新要求嵌入公钥验证的 Ed25519 签名清单，以及必需的安装包 SHA-256。
- 限制官方 HTTPS 发布地址、重定向、下载大小和解压路径；任何验证失败均阻止安装。
- 0.0.59 及更早版本需要从官方发布页手动安装本次安全升级，才能建立签名验证信任。旧更新清单不再提供可自动执行的安装包。
- 未配置有效发布公钥时，自动更新保持关闭并提示官方手动下载；没有真实签名不能发布为已完成的签名更新。

## 行情与凭据

- macOS 菜单栏及工作模式状态使用统一行情记录的真实时间和新鲜度，不再用当前电脑时间伪装行情已更新。
- 主数据源返回过期或时间未知的报价时尝试备用源；较差备用结果不会覆盖较新证据。
- macOS 凭据直接使用 Security.framework，不再将密码放进命令行参数。保留原有服务和账户标识。
- Linux/Windows 凭据工具增加超时和有界输出，错误信息不回显密码。

## 验证与边界

新增签名篡改、非法更新地址、缺失散列、恢复只读、原始字节保留、有序后台保存、过期行情回退和凭据超时回归测试。
发布必须通过 Linux、Windows、macOS arm64/x64 的原生 CI；Linux 截图检查不替代 macOS/Windows 真机视觉验收。

本软件用于研究与本地记录，不执行券商交易。macOS 安装包仍采用 ad-hoc 签名，未公证。
