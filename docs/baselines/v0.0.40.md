# v0.0.40 architecture baseline

Captured on 2026-08-09 before architecture-v2 changes, on macOS arm64 with Rust 1.93.1.

| Gate | Baseline |
|---|---|
| `cargo fmt --all -- --check` | failed; 4,650 diff lines reported |
| `cargo check --all-targets` | passed with 74 warnings |
| `cargo clippy --all-targets -- -D warnings` | failed with 137 errors |
| `cargo test --all-targets` | 88 passed, 12 ignored |

The 50 `unexpected_cfgs` diagnostics originate in the legacy `objc` macro expansion and are
scoped only to `mac_gesture.rs` and `mac_status_bar.rs`. Network smoke tests are ignored in PR
runs and executed by the nightly workflow.

Performance budgets retained for the architecture freeze:

- cold start p95: 1.5 seconds
- cached navigation p95: 100 ms
- chart frame p95/p99: 16.7/33 ms
- apply 100 quotes p95: 50 ms
- score 1,000 symbols: 200 ms
- idle RSS: 250 MB; one-hour growth: 10%

Reference window sizes are 720×440, 920×580, and 1280×800. UI regression screenshots are
captured by the GPUI layout tests rather than checked in as machine-dependent bitmaps.
